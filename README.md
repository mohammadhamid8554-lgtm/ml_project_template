# Generic ML Project Template

This project is a clean starter template for machine learning and data science work.

## Purpose

This template keeps the project structure simple, readable, and reusable across future ML projects.

## Structure

- src/project_name: main package
- components: data ingestion, transformation, and model training
- pipelines: training + prediction workflow
- config: settings and paths
- entity: data classes
- tests: validation scripts

## Setup

1. Create a virtual environment
2. Install dependencies
3. Run the training pipeline

## Run

```bash
python app.py
```

## Common flow

- data ingestion
- preprocessing
- model training
- artifact saving
- prediction
